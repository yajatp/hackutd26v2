## Why a row can differ

- **Inputs from noisy readings.** On the snapshots, Avon reads the tank level and the wells' water rates from telemetry.csv at "now" (a 6-sample fit for the level, a 1-hour mean for the water). The answer key planned from exact values (`level_final_pct`, baseline water). The planner itself is exact on exact inputs: it matches all 91 cases written from the Python prototype and all 13 full-week cases above. So a difference on a snapshot is a difference in the measured inputs, which moves a late shut-in start by a few minutes and its cost by tens of dollars. The decision (which trucks, which wells) is the same.
- **Shut-in start rounding.** Starts are whole minutes, strictly before the exact latest start: touching the shutdown limit counts as a trip (answer key EVENT_21: exact 52.000 becomes +51).
- **Shared trucks.** Failures in one system are planned together, so a cheaper truck plan for one tank can lose to a plan that keeps the truck for another tank. The fix card says which tanks share the fleet.
